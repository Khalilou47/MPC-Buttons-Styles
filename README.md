# MPC-Buttons-Styles
Buttons styles for Media Player Classic

01- Extract the folder to this location:
C:\Program Files\MPC-HC\Toolbars

02- Open MPC

03- Go to View -> Options

04- On the left menu choose Toolbar

05- In the Main Windows Go to Toolbar Style -> Active Style

06- In the dropdown menu choose 'Watch Dogs Style'

07- Click Apply

Done!
